# 需求变更建议：缺陷类别与工艺知识关联

日期：2026-11-09。此文件是对需求说明 V0.2 的建议，**不替代或静默改写原需求**。建议三人小组与课程教师确认后，再决定是否纳入正式验收范围。

## 新增目标

在现有 NEU-CLS 六分类输出之后，增加面向质量管理人员的工艺问题辅助分析：按预测类别展示可能涉及的工序、文献报道的候选形成机制、建议核查的条件、资料来源与不确定性。分类标签不能直接解释为根因，系统不得自动下达工艺参数调整建议。

## 第二阶段建议实现

1. 建立人工审阅的结构化知识表，至少包含类别、工序、候选机制、适用条件、文献出处、核查建议和审核状态。
2. 在推理接口和 Streamlit 原型中同时展示类别、模型输出分布、知识表条目及“仅供核查”的提示；类别不确定时提示人工复核。
3. 逐条核对知识条目的原文和适用范围，避免把冶炼、连铸、加热、热轧、冷却及后续加工混为同一工序。

## 验收建议与边界

分类部分沿用独立测试集 Accuracy、Macro-F1、逐类指标和混淆矩阵。知识关联部分由人工检查条目的可追溯性、准确性、覆盖范围与不确定性表达，不以 NEU-CLS 计算“根因诊断准确率”，因为该数据集没有经核实的工艺根因和过程参数。正常/异常筛查、缺陷定位、工业实时部署和自动工艺优化均不属于本变更。
